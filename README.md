1) При сохранении double теряет "копейку" от десятичных дробей, если это какие то финансовые расчеты это критично, поэтому для них используют decimal.

3) Тип var определяется один раз, во время компиляции. В python тип определяется в момент присвоения значения переменной, так же само значение может меняться (независимо от типа) уже в процессе выполнения программы. У var значение переменной определяется один раз и больше не изменяется.
4)  Console.ReadLine() всегда возвращает тип данных string, независимо от значения.
5) При некорректном вводе в int.Parse программа упадет с ошибкой. А при int.TryParse ошибки не будет.
6) Метод вернет значение false, что означает "попытка не удалась", а в переменную переданную через out вернет 0.
7) TryPrase следует использовать, когда ты не уверен, что именно введет пользователь,иначе программа упадет из за ошибки. Parse нужно использовать будучи уверенным в вводимом формате.
